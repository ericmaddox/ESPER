# Project Rules & Guidelines

## Git & Remote Repository Safety
- **DO NOT PUSH TO GITHUB / REMOTES**: Never push code, branches, or tags to GitHub or any remote repository (via `git push`, MCP tools like `git_push`, or command scripts) unless the user explicitly and directly requests a push in the prompt.

## UI & Design Standards
- **STRICT NO-EMOJIS RULE**: NEVER use emojis anywhere in the codebase, UI, labels, tooltips, DOM markers, popups, logs, or comments. Always use professional, sleek SVG vector icons (e.g. Lucide icons or custom tactical SVG paths) and clean typography.
- **STRICT VENDOR & BRAND NAME NEUTRALITY**: NEVER use proprietary company or brand names anywhere in the codebase, UI, mock/demo data, variable names, comments, or documentation (e.g., NEVER use *Skydio*, *ShotSpotter*, *Caltrans*, *Esri*, *Flock*, *Axon*, *Motorola*, *Palantir*, etc.). Always use vendor-neutral tactical and domain-standard terminology (e.g., *Tactical UAS / DFR*, *Acoustic Gunfire Array*, *Regional DOT Traffic*, *Global Satellite HD*, *ALPR Grid*).
